# Ограничения абортов и трудовые доходы в США

Панель SIPP за январь 2021 — декабрь 2024: **714 996 наблюдений «человек × месяц», 25 872 человека, 48 месяцев**. Выбрана панель `SPANEL = 2022`; месячные истории собраны при ежегодных интервью. В данных сохранены оба пола, все возраста и строки с пропущенным доходом.

## Загрузка

Выполнять из корня проекта. Для работы нужны pandas; для графиков — также matplotlib и numpy.

```python
import pandas as pd

# Текущая версия для графиков: 51 столбец.
path = "abortion_research_data.csv.gz"
# Сокращённая версия: path = "data_prep/abortion_research_data.csv.gz"

df_research = pd.read_csv(
    path,
    parse_dates=["date"],
    dtype={"person_id": "string"},
)
df_research["female_flag"] = df_research["female_flag"].astype("Int8")
df_research["restriction_flag"] = df_research["restriction_flag"].astype("Int8")
```

Ключ строки — **`person_id + date`**, дубликатов нет. CSV не сохраняет тип даты: `parse_dates` нужен для правильного сопоставления с календарём и построения линий. `Int8` поддерживает пропуски флага; заменять неопределённый статус нулём нельзя.

## Как собрана таблица

Из выпусков SIPP 2022–2025 объединены месяцы 2021–2024 для панели 2022. Затем отобраны показатели, присоединены ограничения по месячному штату `TEHC_ST`, году и месяцу, переименованы рабочие поля и созданы `person_id`, `date`, `state`, `female_flag`. Последний этап ноутбука оставляет 19 столбцов и сохраняет файл в `data_prep/`.

Для повторной сборки нужно распаковать архив и настроить пути в `data_prep.ipynb`: там пока остаются абсолютные ссылки на прежнюю рабочую папку. Корневой CSV с 51 столбцом автоматически не обновляется при сохранении версии с 19 столбцами.

## Что означают основные показатели

- `female_flag`: 1 — женщина, 0 — мужчина; код следует текущей строке.
- `income` и `income_alt`: номинальные месячные трудовые доходы, включая самостоятельную деятельность. Нули и настоящие отрицательные значения сохранены, пропуски нулями не заменены. CPI пока не присоединён.
- `weekly_hours`: среднее число часов **в неделю** в соответствующем месяце.
- `restriction_flag`: **статус на конец месяца** — после подготовки скопирован из `restriction_month_end`. Учитываются основные полные и ранние запреты со сроком строго менее 20 недель LMP. Ноль не означает отсутствие всех видов ограничений.
- `household_children_u18`: все несовершеннолетние домохозяйства; собственных детей нужно рассчитывать отдельно с использованием семейных связей из расширенной версии.
- `survey_weight`: месячный вес Census. В текущих графиках веса не применяются; способ взвешивания для анализа ещё предстоит выбрать.

Карта использует правовые статусы из `df_research` и отдельные контуры Census 2024. Перед запуском нужно задать путь `BOUNDARY_FILE` или передать `boundary_file` в функцию карты.
