# SIPP: рабочие данные для исследования Dobbs, 2021–2024

Обновлено 8 ноября 2026 года.

Проект содержит месячную панель SIPP для исследования трудовых доходов, занятости и гендерного разрыва в штатах США с разными режимами ограничений абортов. Рабочий файл — [abortion_research_data.csv.gz](abortion_research_data.csv.gz): **714 996 строк, 51 столбец, 25 872 человека**. Единица наблюдения — человек × календарный месяц.

Период — январь 2021 — декабрь 2024, 48 месяцев. Выбрана панель `SPANEL = 2022`: выпуски SIPP 2022–2025 описывают соответственно 2021–2024 календарные годы. Месячные истории собираются ретроспективно при ежегодных интервью.

В рабочем CSV сохранены мужчины и женщины всех возрастов, в том числе наблюдения с пропущенным доходом. Панель несбалансированная. В `data_check.ipynb` графики строятся для женщин с известным штатом проживания.

## Загрузка рабочего набора

Для просмотра данных нужны pandas и Jupyter; для графиков также используются matplotlib и numpy. Запускать `data_check.ipynb` следует с рабочей папкой в корне проекта и выполнять ячейки последовательно.

```python
import pandas as pd

df_research = pd.read_csv(
    "abortion_research_data.csv.gz",
    compression="gzip",
    parse_dates=["date"],
    dtype={"person_id": "string", "SSUID": "string", "PNUM": "string"},
)

df_research["date"] = (
    df_research["date"].dt.to_period("M").dt.to_timestamp()
)

for col in [
    "female_flag", "restriction_flag", "restriction_month_end",
    "restriction_days_confirmed", "restriction_days_uncertain",
    "policy_uncertain", "policy_covered",
]:
    df_research[col] = df_research[col].astype("Int8")

df_research["restriction_share"] = (
    df_research["restriction_share"].astype("Float64")
)
```

CSV не хранит типы pandas. Без `parse_dates` дата после повторной загрузки становится текстом. При сопоставлении такого индекса с календарём `DatetimeIndex`, например через `reindex(calendar)`, значения не совпадут и линии на графиках могут исчезнуть. Тип `Int8` сохраняет пропуски в правовых флагах; заполнять их нулями для преобразования в обычный `int` нельзя.

В готовом `person_id` часть `SSUID` дополнена до 14 знаков. В отдельном столбце `SSUID` ведущие нули уже могли быть потеряны при предыдущем числовом импорте: чтение как строки само по себе их не восстанавливает. Для связи наблюдений внутри рабочего набора используется `person_id`.

## Структура и изменения переменных

Уникальный ключ строки — **`person_id + date`**. Исходный эквивалент: `SSUID + PNUM + reference_year + MONTHCODE`. В сохранённом CSV дубликатов ключа нет.

| Рабочее имя | Исходное имя SIPP | Смысл |
| --- | --- | --- |
| `income` | `TPEARN` | Номинальный месячный трудовой доход от всех работ, включая прибыль/убытки от самостоятельной деятельности; доллары США. Зависит от числа дней месяца. |
| `income_alt` | `TPEARN_ALT` | Альтернативный номинальный месячный трудовой доход без зависимости от числа дней месяца. |
| `weekly_hours` | `TMWKHRS` | Среднее число рабочих часов **в неделю** по всем работам в соответствующем месяце. |
| `employment_status_code` | `RMESR` | Исходная месячная категория занятости, коды 1–8. |
| `age` | `TAGE_EHC` | Возраст в соответствующем месяце, в публичной кодировке Census. |
| `race_code` | `ERACE` | Категория расы в публичном файле. |
| `education_code` | `EEDUC` | Наивысший завершённый уровень образования к декабрю референтного года. Коды обозначают категории, не число лет обучения. |
| `marital_status_code` | `EMS_EHC` | Семейное положение в соответствующем месяце. |
| `household_size` | `RHNUMPER` | Число людей в домохозяйстве в месяце. |
| `household_children_u18` | `RHNUMU18` | Число всех несовершеннолетних в домохозяйстве. |
| `survey_weight` | `WPFINWGT` | Итоговый месячный вес человека. |

Добавлены четыре поля:

| Поле | Определение |
| --- | --- |
| `person_id` | Строка из 14-значного `SSUID`, знака `_` и `PNUM`; идентификатор одного человека между месяцами. |
| `date` | Первое число календарного месяца, собранное из `reference_year` и `MONTHCODE`. |
| `state` | Название штата по месячному коду `TEHC_ST`. |
| `female_flag` | `1` — женщина (`ESEX = 2`), `0` — мужчина (`ESEX = 1`); неизвестный исходный код при построении остаётся пропуском. |

В текущем файле используется имя **`female_flag`**. Полей `female` и `income_observed` нет. Флаг пола следует значению текущей строки; фиксированная группировка по полу в начале панели не строилась.

Исходные идентификаторы, год, месяц, панель, волна, географические коды, семейные указатели и флаги качества сохранены. Поля `release_year` и `source_file` из расширенного набора в рабочем CSV отсутствуют.

## Доходы, пропуски и семейные связи

Для `income` и `income_alt` выполнено преобразование в числовой формат. Нечисловые значения, служебный код `-100000998` и бесконечности заменены пропусками. Настоящие нулевые и остальные отрицательные доходы сохранены. Отрицательный трудовой доход может отражать убыток от самостоятельной деятельности.

В `income` **326 934 заполненных значения**, в том числе **10 821 нулевое и 3 814 отрицательных**; **388 062 значения пропущены**. Пропуск не означает нулевой доход или отсутствие занятости. Импутации Census и их флаги сохранены; дополнительная импутация при подготовке не выполнялась.

`income` включает самостоятельную деятельность и не является отдельной зарплатой только от наёмной работы. Деление месячного дохода непосредственно на `weekly_hours` не даёт почасовую оплату. Индекс CPI ещё не присоединён, поэтому оба показателя дохода остаются номинальными.

`household_children_u18` описывает всех несовершеннолетних домохозяйства. Собственных совместно проживающих детей и возраст младшего ребёнка пока не рассчитывали. В сохранённом CSV есть `RPNPAR1_EHC`, `RPNPAR2_EHC`, `RPAR1TYP_EHC`, `RPAR2TYP_EHC`. Для восстановления семейных связей нужны строки детей, их возраст, указатели родителей, тип связи и совместное проживание по `SSUID + date + ERESIDENCEID`.

## Ограничения в штате

Правовые сведения присоединены по **`TEHC_ST + reference_year + MONTHCODE`**. `TEHC_ST` — штат проживания в соответствующем месяце; `TST_INTV` — штат на момент интервью и для назначения ограничения не используется.

Коллекция включает 50 периодов основных полных и ранних гестационных запретов с порогом **строго менее 20 недель LMP** в 25 штатах. Таблица охвата перечисляет 50 штатов и DC. Ноль означает отсутствие соответствующего учтённого запрета по правилам коллекции, а не отсутствие всех видов ограничений или гарантированный доступ к услугам.

**В текущем рабочем CSV `restriction_flag` означает статус на последнюю календарную дату месяца и полностью совпадает с `restriction_month_end`, включая пропуски.** В ноутбуке подготовки выполнено присваивание:

```python
df_research["restriction_flag"] = pd.to_numeric(
    df_research["restriction_month_end"], errors="coerce"
).astype("Int8")
```

Сама функция `add_restriction_flag()` первоначально создаёт `restriction_flag` по правилу «хотя бы один подтверждённый день». Эта первоначальная версия поля в итоговом файле перезаписана. При повторной подготовке порядок этих операций влияет на смысл флага.

| Поле | Смысл в текущем CSV |
| --- | --- |
| `restriction_flag` | Статус на конец месяца: `1` — подтверждённый запрет; `0` — по коллекции запрет не действует и статус определён; `NA` — определить статус нельзя. |
| `restriction_month_end` | Исходное поле статуса на последнюю дату месяца; совпадает с текущим `restriction_flag`. |
| `restriction_share` | Доля календарных дней месяца с подтверждённым запретом, от 0 до 1. При неопределённости или неполном временном охвате — `NA`. |
| `restriction_days_confirmed` | Число дней с подтверждённым запретом. При неопределённости содержит только подтверждённую часть. |
| `restriction_days_uncertain` | Число дней с неоднозначным статусом или вне временного охвата коллекции. |
| `policy_uncertain` | `1`, если в месяце есть неопределённые дни; `0` в противном случае; `NA`, если нет сопоставления. Может равняться 1 при известном статусе на конец месяца. |
| `policy_covered` | `1`, если весь месяц входит в заявленный временной охват штата; `0`, если нет; `NA`, если нет сопоставления. Не подтверждает полноту учёта всех видов законов. |

В `restriction_flag` **145 546 единиц, 561 124 нуля и 8 326 пропусков**. Код `TEHC_ST = 61` означает Foreign Country: таких строк **1 339**, у них название штата и правовые поля пропущены. Они сохранены в рабочем CSV и исключаются из графиков по штатам через отсутствие `state`.

Начало правового периода включается, `end_date_exclusive` не включается. Конец окна `2025-01-01` не считается отменой закона. Альтернативные даты, спорная применимость старых законов и фактическое закрытие клиник учитываются отдельно. Пересечения периодов не приводят к двойному счёту дней.

Подробные правовые исходники находятся в `data_collection_gpt/policy/` внутри архива: `restriction_spells.csv`, `state_coverage.csv`, `court_and_timing_events.csv`, `policy_sources.csv`, исходные выгрузки LawAtlas и 51 запись на начало 2021 года. История всех поздних сроков, исключений, методов, финансирования, ожидания и иных ограничений за 2021–2024 годы не сведена в один флаг. В исходниках LawAtlas перечислены и заблокированные законы: сами названия или сроки не доказывают их действие.

## Графики в `data_check.ipynb`

Графики используют только рабочий `df_research` и уже присоединённые флаги. Отбор — `female_flag == 1`, известные `state` и `date`. Дополнительный возрастной фильтр не задан. Всего в этой выборке **366 753 человеко-месяца**, доход заполнен в **154 238**.

Средний доход рассчитывается отдельно для каждого штата и месяца обычным `.mean()` по непустым `income`, включая нули и отрицательные значения. Веса не применяются. Среднее относится к наблюдениям с известным доходом; строки с пропуском дохода не становятся нулевыми.

- Синий цвет — `restriction_flag = 0`.
- Красный — `restriction_flag = 1`.
- Серый — неопределённый статус.
- Красная штриховая линия — переход между соседними месяцами `0 → 1`.
- Зелёная точечная линия — переход `1 → 0`.

Вертикальные линии показывают **смену месячного статуса**, а не точный день изменения закона. Переходы через `NA` не считаются подтверждённым началом или окончанием. По месячным флагам нельзя восстановить все внутримесячные приостановления и возобновления запрета.

На каждой странице показано до девяти штатов; шкала дохода общая. Легенда и комментарий находятся на первой странице. `N` рядом со штатом — число наблюдений **женщина × месяц с заполненным доходом за весь показанный период**, не число уникальных людей. `monthly` содержит средние, `n_income` и правовой флаг для каждого штата-месяца.

## Веса

Вес отражает, сколько людей целевого населения представляет участник обследования с учётом отбора и корректировок Census. В рабочем CSV месячный вес сохранён как `survey_weight`. Его наличие не меняет результат обычного `.mean()`.

В архивной папке `data_collection_gpt/weights/` сохранены шесть пар продольных основных и 240 повторных весов для периодов 2021–2022, 2022–2023, 2021–2023, 2023–2024, 2022–2024 и 2021–2024. Повторные веса нужны для оценки погрешности с учётом дизайна обследования; `GVARSTR` и `GHLFSAM` также сохранены в рабочем CSV. Большие месячные файлы повторных весов в комплект не включены.

Веса перекрывающихся панелей Census требуют отдельного обоснования при выборе только `SPANEL = 2022`. Универсальный продольный вес для всех строк этой несбалансированной панели не выбран. При оценке причинного эффекта выбор взвешивания зависит от целевой группы и спецификации; повторные веса не заменяют решение о зависимости наблюдений внутри штатов в DiD. [Census: Weighting](https://www.census.gov/programs-surveys/sipp/methodology/weighting.html), [Solon, Haider, Wooldridge](https://www.nber.org/papers/w18859).

Код анализа в корневом `data_check.ipynb` использует относительный путь к готовому CSV. Набор данных, подробный словарь и notebook подготовки описывают разные стадии работы; сохранённые выводы старых ячеек не заменяют последовательный запуск текущего текста.

## Следующий этап анализа

Пока не созданы реальные доходы, отдельная зарплата только от наёмной работы, бинарный индикатор занятости, группы исходного дохода, число собственных детей и возраст младшего собственного ребёнка. В рабочем CSV отсутствует также `income_observed`: для подсчёта известных доходов используется `income.notna()` или `.count()`.

До оценки эффектов необходимо определить аналитическую выборку, правило классификации пола во времени, исходные доходные группы, смысл показателя занятости, временную привязку контролей и способ применения весов. Число детей и другие характеристики, способные измениться после запрета, требуют явного выбора роли в спецификации. Оценки DiD/DDD и проверки предпосылок пока не выполнены.
